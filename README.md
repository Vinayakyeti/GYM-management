# GYM Management System

A simple web app built with HTML, CSS, JS, and Firebase.

## Features

- **Admin**: Manage members, bills, packages & notifications
- **Members**: View receipts & alerts
- **Users**: View details & search

## Setup

1. Clone repo
2. Add Firebase credentials to `.env`
3. Open `index.html` in browser (use Vite or Live Server)

## Tech Stack

HTML, CSS, JS, Firebase

## Notes

- UI minimal and responsive
- Basic logging added
- Code kept lightweight for clarity
